## Apa itu CedPrinter

**CedPrinter** adalah aplikasi untuk **membuat dan mencetak label di printer Zebra (ZPL)**, dibuat untuk **Cedisa Central de Aço** dan terbuka untuk siapa saja. Gratis, **tanpa iklan**, dan tersedia dalam bahasa Portugis (Brasil). Kode sumbernya bersifat privat; di sini tersedia installer dan versi-versi yang dirilis.

Aplikasi ini menyusun label dalam **ukuran persis sesuai media Anda** lalu langsung mengirimnya ke printer, sehingga ukuran dan posisi cetak selalu tepat.

## Fitur unggulan

- **Desainer visual:** teks, barcode (Code 128, Code 39, EAN-13/8, UPC-A, ITF), QR Code, Data Matrix, PDF417, gambar, ikon, bentuk, dan garis.
- **Pengeditan sungguhan:** pilih banyak objek, rata dan distribusi, pemandu, lapisan, salin/tempel, urungkan/ulangi.
- **Cetak berseri:** impor spreadsheet (Excel/CSV) dan cetak satu label per baris, lengkap dengan nomor seri.
- **Tanggal terhitung:** `{_data+30}` untuk masa berlaku dan berbagai format.
- **QR dengan panduan:** Pix, Wi-Fi, tautan, kontak, WhatsApp, e-mail, SMS, dan peta. **Validasi** kode sebelum dicetak.
- **PDF dan gambar:** cetak dalam ukuran asli atau bawa ke Desainer untuk diedit.
- **Templat siap pakai** dan pustaka pribadi, riwayat, dan label cepat.
- **Cetak langsung (ZPL):** lewat jaringan (IP), USB/Windows, Wi-Fi, Bluetooth, dan USB (Android).
- **Pembaruan otomatis**, lengkap dengan daftar perubahan.

## Unduh

**➡️ [Buka versi terbaru](https://github.com/arthurbrito-pjt/CedPrinter-releases/releases/latest)** lalu unduh berkas dari daftar **Assets**:

| Berkas | Fungsi |
|---|---|
| `CedPrinter-Setup-X.exe` | **Installer Windows** (disarankan). Memperbarui diri sendiri. |
| `CedPrinter-PC-X.zip` | Versi portabel Windows, tanpa instalasi. Tidak memperbarui diri sendiri. |
| `CedPrinter-X.apk` | **Aplikasi Android** (ponsel dan perangkat kolektor data). |

> `latest.yml` adalah berkas internal untuk pembaruan: tidak perlu diunduh.

## Instal

### 🖥️ Windows

1. Unduh `CedPrinter-Setup-X.exe` lalu buka.
2. Jika Windows menampilkan peringatan "Windows melindungi PC Anda", klik **Info lebih lanjut → Tetap jalankan** (installer belum memiliki tanda tangan kode).
3. Ikuti panduan instalasi dan klik **Instal**.
4. Pada penggunaan pertama, klik tombol printer di bagian atas layar dan pilih Zebra Anda.

### 📱 Android

1. Unduh `CedPrinter-X.apk` di perangkat lalu buka berkasnya.
2. Jika Android memintanya, izinkan **instal aplikasi tidak dikenal** untuk browser atau pengelola berkas yang Anda gunakan.
3. Buka CedPrinter, masuk ke **Printer** dan pilih Zebra Anda (Wi-Fi, Bluetooth, atau USB).

## Pertanyaan umum

**Printer apa saja yang didukung?** Printer **Zebra dengan ZPL** (acuan: ZD230, 203 dpi), lewat jaringan, USB, atau Bluetooth. Merek lain tidak kompatibel.

**Apakah perlu internet?** Hanya untuk mengunduh aplikasi dan pembaruan. Mencetak dan membuat label dapat dilakukan secara offline.

**Apakah aplikasi mengumpulkan data saya?** Tidak. Templat, riwayat, dan pengaturan Anda tersimpan di komputer Anda. Aplikasi hanya memeriksa GitHub ini untuk mengetahui apakah ada versi baru.

**Apakah gratis?** Ya, untuk penggunaan pribadi maupun komersial. Lihat [ketentuan penggunaan](LICENSE) (dalam bahasa Portugis).

**Saya menemukan masalah atau punya ide.** Buka sebuah [issue](https://github.com/arthurbrito-pjt/CedPrinter-releases/issues/new/choose) dengan menyebutkan versi dan, jika memungkinkan, printer yang dipakai.
