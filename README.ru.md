## Что это

**CedPrinter** — приложение для **создания и печати этикеток на принтерах Zebra (ZPL)**. Оно сделано для **Cedisa Central de Aço** и открыто для всех. Бесплатное, **без рекламы**, на 100% на португальском языке. Исходный код закрыт; здесь находятся установщики и опубликованные версии.

Приложение формирует этикетку в **точном размере вашего носителя** и отправляет её прямо на принтер, поэтому размер и положение всегда получаются правильными.

## Возможности

- **Визуальный дизайнер:** текст, штрихкоды (Code 128, Code 39, EAN-13/8, UPC-A, ITF), QR-код, Data Matrix, PDF417, изображения, значки, фигуры и линии.
- **Полноценное редактирование:** множественное выделение, выравнивание и распределение, направляющие, слои, копирование/вставка, отмена/повтор.
- **Серийная печать:** импортируйте таблицу (Excel/CSV) и печатайте по одной этикетке на строку, с порядковым номером.
- **Вычисляемые даты:** `{_data+30}` для срока годности и множество форматов.
- **QR-код с помощником:** Pix, Wi-Fi, ссылка, контакт, WhatsApp, e-mail, SMS и карта. **Проверка** кодов перед печатью.
- **PDF и изображения:** печатает в натуральную величину или передаёт в Дизайнер для редактирования.
- **Готовые шаблоны** и собственная библиотека, история и быстрая этикетка.
- **Прямая печать (ZPL):** по сети (IP), USB/Windows, Wi-Fi, Bluetooth и USB (Android).
- **Автоматическое обновление** с описанием изменений.

## Установка

### 🖥️ Windows

1. Скачайте `CedPrinter-Setup-X.exe` и запустите его.
2. Если Windows покажет сообщение «Система Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае** (у установщика пока нет цифровой подписи).
3. Следуйте указаниям мастера и нажмите **Установить**.
4. При первом запуске нажмите кнопку принтера в верхней части экрана и выберите свой Zebra.

### 📱 Android

1. Скачайте `CedPrinter-X.apk` на устройство и откройте файл.
2. Если Android попросит, разрешите **установку неизвестных приложений** для используемого браузера или файлового менеджера.
3. Откройте CedPrinter, перейдите в раздел **Принтеры** и выберите Zebra (Wi-Fi, Bluetooth или USB).

## Часто задаваемые вопросы

**Какие принтеры подходят?** Принтеры **Zebra с поддержкой ZPL** (эталон: ZD230, 203 dpi) — по сети, USB или Bluetooth. Другие марки не поддерживаются.

**Нужен ли интернет?** Только для загрузки приложения и обновлений. Печать и создание этикеток работают офлайн.

**Собирает ли приложение мои данные?** Нет. Ваши шаблоны, история и настройки хранятся на вашем компьютере. Приложение обращается сюда, на GitHub, только чтобы проверить наличие новой версии.

**Это бесплатно?** Да, как для личного, так и для коммерческого использования. Ознакомьтесь с [условиями использования](LICENSE) (на португальском).

**Нашёл проблему или есть идея.** Создайте [issue](https://github.com/arthurbrito-pjt/CedPrinter-releases/issues/new/choose), указав версию и, по возможности, модель принтера.
