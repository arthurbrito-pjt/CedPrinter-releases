## یہ کیا ہے

**CedPrinter** ایک ایپلیکیشن ہے جس سے **Zebra (ZPL) پرنٹرز پر لیبلز بنائے اور پرنٹ کیے جا سکتے ہیں**۔ اسے **Cedisa Central de Aço** کے لیے بنایا گیا ہے اور یہ ہر کسی کے لیے کھلی ہے۔ یہ مفت ہے، **اشتہارات سے پاک** ہے اور مکمل طور پر پرتگالی زبان میں ہے۔ سورس کوڈ نجی ہے؛ یہاں انسٹالرز اور جاری کردہ ورژنز موجود ہیں۔

یہ لیبل کو آپ کے میڈیا کے **عین سائز** میں تیار کرتی ہے اور سیدھا پرنٹر کو بھیجتی ہے، اس لیے سائز اور پوزیشن ہمیشہ درست آتی ہے۔

## نمایاں خصوصیات

- **بصری ڈیزائنر:** متن، بار کوڈز (Code 128، Code 39، EAN-13/8، UPC-A، ITF)، QR Code، Data Matrix، PDF417، تصاویر، آئیکنز، شکلیں اور لکیریں۔
- **حقیقی ایڈیٹنگ:** متعدد انتخاب، ترتیب اور تقسیم، گائیڈز، لیئرز، کاپی/پیسٹ، کالعدم/بحال۔
- **سیریز میں پرنٹنگ:** اسپریڈ شیٹ (Excel/CSV) درآمد کریں اور ہر قطار کے لیے ایک لیبل پرنٹ کریں، سیریل نمبر کے ساتھ۔
- **حساب شدہ تاریخیں:** میعاد کے لیے `{_data+30}` اور کئی فارمیٹس۔
- **اسسٹنٹ کے ساتھ QR:** Pix، Wi-Fi، لنک، رابطہ، WhatsApp، ای میل، SMS اور نقشہ۔ پرنٹ سے پہلے کوڈز کی **توثیق**۔
- **PDF اور تصویر:** اصل سائز میں پرنٹ کریں یا ایڈیٹنگ کے لیے ڈیزائنر میں لے جائیں۔
- **تیار ٹیمپلیٹس** اور اپنی لائبریری، ہسٹری اور فوری لیبل۔
- **براہِ راست پرنٹنگ (ZPL):** نیٹ ورک (IP)، USB/Windows، Wi-Fi، Bluetooth اور USB (Android) کے ذریعے۔
- **خودکار اپ ڈیٹ**، جس میں بتایا جاتا ہے کہ کیا بدلا۔

## ڈاؤن لوڈ

**➡️ [تازہ ترین ورژن کھولیں](https://github.com/arthurbrito-pjt/CedPrinter-releases/releases/latest)** اور **Assets** کی فہرست سے فائل ڈاؤن لوڈ کریں:

| فائل | مقصد |
|---|---|
| `CedPrinter-Setup-X.exe` | **Windows انسٹالر** (تجویز کردہ)۔ خود بخود اپ ڈیٹ ہوتا ہے۔ |
| `CedPrinter-PC-X.zip` | Windows کا پورٹیبل ورژن، انسٹالیشن کے بغیر۔ خود بخود اپ ڈیٹ نہیں ہوتا۔ |
| `CedPrinter-X.apk` | **Android ایپلیکیشن** (موبائل اور کلیکٹر)۔ |

> `latest.yml` اپ ڈیٹ کی اندرونی فائل ہے: اسے ڈاؤن لوڈ کرنے کی ضرورت نہیں۔

## انسٹال کریں

### 🖥️ Windows

1. `CedPrinter-Setup-X.exe` ڈاؤن لوڈ کر کے کھولیں۔
2. اگر Windows "Windows نے آپ کے پی سی کو محفوظ کیا" کی وارننگ دے تو **مزید معلومات ← پھر بھی چلائیں** پر کلک کریں (انسٹالر پر ابھی کوڈ سائننگ نہیں ہے)۔
3. وزرڈ کی ہدایات پر عمل کریں اور **انسٹال کریں** پر کلک کریں۔
4. پہلی بار استعمال پر، اسکرین کے اوپر پرنٹر کے بٹن پر کلک کریں اور اپنا Zebra منتخب کریں۔

### 📱 Android

1. اپنے آلے پر `CedPrinter-X.apk` ڈاؤن لوڈ کریں اور فائل کھولیں۔
2. اگر Android کہے تو استعمال ہونے والے براؤزر یا فائل مینیجر کے لیے **نامعلوم ایپس انسٹال کرنے** کی اجازت دیں۔
3. CedPrinter کھولیں، **پرنٹرز** میں جائیں اور Zebra منتخب کریں (Wi-Fi، Bluetooth یا USB)۔
