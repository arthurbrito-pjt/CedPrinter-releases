## CedPrinterとは

**CedPrinter**は、**Zebraプリンター(ZPL)でラベルを作成・印刷する**ためのアプリです。**Cedisa Central de Aço**のために作られ、誰でも自由に使えます。無料で、**広告なし**、そして100%ポルトガル語表示です。ソースコードは非公開で、ここにはインストーラーと公開済みのバージョンを置いています。

ラベルを**お使いのメディアの正確なサイズ**で作成し、そのままプリンターへ送信するので、サイズも位置も常にぴったり仕上がります。

## 主な機能

- **ビジュアルデザイナー:** テキスト、バーコード(Code 128、Code 39、EAN-13/8、UPC-A、ITF)、QRコード、Data Matrix、PDF417、画像、アイコン、図形、線。
- **本格的な編集機能:** 複数選択、整列と等間隔配置、ガイド、レイヤー、コピー/貼り付け、元に戻す/やり直し。
- **シリーズ印刷:** スプレッドシート(Excel/CSV)を読み込んで1行につき1枚のラベルを印刷。シリアル番号にも対応。
- **日付の自動計算:** 有効期限用の`{_data+30}`や、さまざまな書式。
- **ウィザード付きQR:** Pix、Wi-Fi、リンク、連絡先、WhatsApp、メール、SMS、地図。印刷前にコードの**検証**も行います。
- **PDFと画像:** 実寸で印刷するか、デザイナーに取り込んで編集できます。
- **豊富なテンプレート**とオリジナルのライブラリ、履歴、クイックラベル。
- **ダイレクト印刷(ZPL):** ネットワーク(IP)、USB/Windows、Wi-Fi、Bluetooth、USB(Android)に対応。
- **自動アップデート**で、変更内容も確認できます。

## ダウンロード

**➡️ [最新バージョンを開く](https://github.com/arthurbrito-pjt/CedPrinter-releases/releases/latest)** と、**Assets**の一覧からファイルをダウンロードできます。

| ファイル | 用途 |
|---|---|
| `CedPrinter-Setup-X.exe` | **Windows用インストーラー**(推奨)。自動で更新されます。 |
| `CedPrinter-PC-X.zip` | インストール不要のWindowsポータブル版。自動更新はされません。 |
| `CedPrinter-X.apk` | **Androidアプリ**(スマートフォンとハンディ端末)。 |

> `latest.yml`は内部の更新用ファイルです。ダウンロードは不要です。

## インストール

### 🖥️ Windows

1. `CedPrinter-Setup-X.exe`をダウンロードして開きます。
2. 「Windows によって PC が保護されました」と表示されたら、**詳細情報 → 実行** をクリックします(インストーラーにはまだコード署名がありません)。
3. ウィザードに従い、**インストール**をクリックします。
4. 初回は、画面上部のプリンターボタンをクリックして、お使いのZebraを選択します。

### 📱 Android

1. 端末で`CedPrinter-X.apk`をダウンロードし、ファイルを開きます。
2. Androidから求められたら、使用しているブラウザーまたはファイルマネージャーに対して**提供元不明のアプリのインストール**を許可します。
3. CedPrinterを開き、**プリンター**からZebra(Wi-Fi、Bluetooth、USB)を選択します。

## よくある質問

**対応しているプリンターは?** **ZPL対応のZebraプリンター**(基準機種:ZD230、203 dpi)で、ネットワーク、USB、Bluetoothに対応しています。他社製品には対応していません。

**インターネット接続は必要ですか?** アプリとアップデートのダウンロード時のみ必要です。ラベルの作成と印刷はオフラインで動作します。

**アプリは個人データを収集しますか?** いいえ。テンプレート、履歴、設定はお使いのコンピューター内に保存されます。アプリがこのGitHubに問い合わせるのは、新しいバージョンがあるかどうかを確認するときだけです。

**無料ですか?** はい、個人利用でも商用利用でも無料です。[利用条件](LICENSE)(ポルトガル語)をご覧ください。

**問題を見つけた、またはアイデアがあります。** バージョンと、可能であればプリンターの機種を添えて、[issue](https://github.com/arthurbrito-pjt/CedPrinter-releases/issues/new/choose)を作成してください。
